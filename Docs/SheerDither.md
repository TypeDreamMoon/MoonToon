# 薄纱镂空 (Sheer Dither)

薄纱、纱袖、半透明裙摆这类"盖在身体上的一层薄布"，用屏幕抖动镂空来做透：
材质仍然是不透明 GBuffer，每帧按屏幕位置丢掉一部分像素，TSR 把多帧累积起来，看上去就是半透明。
做法来自鸣潮角色界面的纱袖（RenderDoc 2026-10-30，引擎仓 `Toon/WUWA_CHARACTER_RENDERING_ANALYSIS.md` 10.5）。

## 配置

在 **M_MoonToon** 的材质实例上（组 `21 - Translucency`）：

1. 勾 **`Use Sheer Dither`**（静态开关，关着时零开销、着色器不变）。
2. 把实例的 **Blend Mode 覆盖为 Masked**。只有 Masked 实例才走裁剪；不覆盖时开关不起作用。
3. 覆盖率 = `Opacity × Opacity Map`（也就是平常的 OpacityMask），1 = 不透。
   鸣潮的做法是在不透明度图里画织纹：线 ≈0.8、缝 ≈0.65，刺绣和袖口边框画 1。
4. 可选 **`Sheer Emissive Opaque`**（默认 1）：覆盖率 = `max(OpacityMask, 自发光亮度 × 此值)`，
   让闪点、发光花纹在纱上保持实心，不被打孔。0 = 关。

阴影 pass 不抖动，仍然用 `Shadow Opacity` 决定投影的透明度。

## 原理

```
k    = (2·(y+f) + (x+f)) % 5      // f = View.StateFrameIndex % 5，五个相位逐帧轮换
n    = 静态的逐像素噪声 ∈ [0,1)
保留 = (k + n) / 5 >= 1 − 覆盖率
```

五个相位在连续五帧里各轮一次，TSR 把每个像素平均到约等于覆盖率；噪声把同一相位内的阈值打散。
鸣潮把覆盖率 0.8333 当作全不透、用 TAA 抖动序号当 f；这里 1 = 全不透，f 用 `StateFrameIndex`，
不受抖动序列长度影响，五个相位总是均匀轮换。

## 和真半透明怎么选

| | 薄纱镂空 | 真半透明（Translucent + Surface ForwardShading） |
| --- | --- | --- |
| 透出的东西 | 下面各层各自完整打光（皮肤有 toon 主光、阴影、rim） | 下层已打光，纱本身按前向 toon 着色 |
| 排序 | 无排序问题（写深度） | 多层半透明之间可能排序错 |
| 深度 / 速度 | 写满，后处理（DOF、SSR、描边、FaceOverlay）都把纱当成不透明 | 不写深度，后处理看不到纱 |
| 阴影 | 用 `Shadow Opacity` 的不透明阴影 | 半透明阴影另走一套 |
| 运动 | 快速运动、切镜头时有噪点和拖影，要几帧才收敛 | 每帧稳定 |
| 适合 | 贴在身体上、面积不大、动得不快的薄布 | 大面积、远离身体、快速运动的纱，或需要稳定截图的场合 |

经验：纱很暗、下面的皮肤被主光照亮时，10% 的孔就足以让手臂清楚透出来；不需要把覆盖率压得很低。

## 已知限制与可选改进

- **噪声是静态的**：收敛之后屏幕上会留下一层贴着屏幕的细颗粒（相机不动时最明显）。可选改进：噪声也随帧滚动。
- **阴影 pass 不抖动**：纱的投影是整块的。可选改进：阴影 pass 也加一个抖动选项，让投影有透光感。
- 依赖 TSR / TAA 的时间累积；关掉抗锯齿（`r.AntiAliasingMethod 0`）时会直接看到镂空图案。

## 实现位置

`DShader/Materials/Core/M_MoonToon.dsm`，`Sheer_Keep`（Custom 节点）→ `ShadowReplace`（阴影 pass 用未抖动的遮罩）→ `OpacityMask`。
